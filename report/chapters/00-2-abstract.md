# Abstract

Indian households save for several goals at once, such as a child's education, a vehicle, a home and retirement, yet the tools available to them answer only one narrow question at a time. SIP calculators assume that the market returns the same rate every year; fund-rating websites rank funds on past returns without relating them to any goal; brokerage applications show holdings without showing whether a goal is on course. A plan built this way looks precise but hides inflation, the uncertainty of returns and the slow drift of real investments away from the plan.

This project designs, implements, tests and deploys **GoalWise**, a web application for goal-based investment and retirement planning in the Indian context. For every goal the system inflates the cost to the target year, computes the monthly systematic investment plan (SIP) required with an optional yearly step-up, and tests the plan with a Monte Carlo simulation of 10,000 market paths under four return models: a normal distribution, a 12-month block bootstrap of real Indian market history, a GARCH(1,1) model and a two-state hidden Markov model of market regimes. The simulation reports the probability of reaching the goal and the SIP needed for 50%, 75% or 90% certainty. A two-phase retirement planner estimates the chance that a corpus lasts to a chosen age.

A data pipeline loads the net asset values of 14,136 mutual fund schemes from AMFI, with full histories for about 1,500 direct-plan growth funds (2.5 million daily values), together with index and inflation data, and computes risk and return metrics for every fund. A LightGBM model ranks funds within their peer groups, validated walk-forward from 2021 to 2025 against naive baselines and explained with SHAP values; K-Means clusters funds by behaviour and a SARIMA model forecasts inflation. A mean-variance optimiser bounded by a glide path recommends an asset allocation and funds for each goal. A portfolio tracker records real transactions, values them with first-in-first-out cost and XIRR, and raises drift and off-track alerts. A conversational assistant built on a large language model answers questions in plain language by calling the system's own calculations as tools, and grounds its explanations in a knowledge base through retrieval-augmented generation over pgvector.

The system is built with React and TypeScript, FastAPI and SQLAlchemy in Python, and PostgreSQL 16 with pgvector. It is verified by 606 backend tests with 92% code coverage, 71 frontend component tests and 7 browser-driven end-to-end tests that run on every change, and it is deployed at no cost on Vercel, Render and Neon. The evaluation shows that the plan's single-rate SIP reaches its goal in only about half of the simulated futures under all four models, that the fund ranker matches a strong momentum baseline (rank correlation 0.248 against 0.254) while adding explanations, and that the assistant chose the correct tool for 97.1% of 102 test questions, reported every one of 50 reference numbers correctly and invented no unsupported figures in explanations when retrieval was enabled.

**Keywords:** goal-based investing, financial planning, Monte Carlo simulation, GARCH, hidden Markov model, mutual funds, LightGBM, portfolio optimisation, XIRR, retrieval-augmented generation, FastAPI, React.
