# API

_Living document – updated whenever endpoints are added. Last updated: Phase 11._

The complete, interactive specification is generated by FastAPI at **`/docs`** (Swagger UI, with an **Authorize** button for protected endpoints) and **`/openapi.json`**.

**Authentication:** protected endpoints require the header `Authorization: Bearer <access_token>`, obtained from `POST /api/auth/login`. Tokens expire after 60 minutes.

| Method | Path | Auth | Phase | Purpose |
|---|---|---|---|---|
| GET | `/api/health` | None | 0 | API status and database/pgvector connectivity |
| POST | `/api/auth/register` | None | 1 | Create an account (JSON), with an optional `security_question` (one of the list) and `security_answer` (1.2; the sign-up form requires them). `201`, `409` duplicate email, `422` invalid input |
| POST | `/api/auth/login` | None | 1 | OAuth2 password flow (form: `username`, `password`) → access token. `401` on bad credentials |
| GET | `/api/auth/me` | Bearer | 1 | The logged-in user, with their `security_question` (never the answer). `401` if token missing, invalid or expired |
| PATCH | `/api/auth/me` | Bearer | 1.2 | Change `full_name` (the e-mail is the login and cannot change). `200` the user |
| PUT | `/api/auth/password` | Bearer | 1.2 | Change the password (`current_password`, `new_password`). `204`, `400` current password wrong, `422` weak password |
| GET | `/api/auth/security-questions` | None | 1.2 | The questions to choose from |
| PUT | `/api/auth/security-question` | Bearer | 1.2 | Set or change the question (`question`, `answer`, `current_password`). `200`, `400` current password wrong |
| POST | `/api/auth/forgot-password/question` | None | 1.2 | Step 1 of "forgot password": `{email}` → `{question}`. An address without an account or a question gets the same stand-in question every time, so accounts cannot be discovered |
| POST | `/api/auth/forgot-password/reset` | None | 1.2 | Step 2: `{email, answer, new_password}`; the answer ignores capitals and extra spaces. `204`, `400` no match (audited), `429` after 5 wrong answers within an hour for that address |

| GET | `/api/risk/questionnaire` | Bearer | 2 | Questions and options (no points) |

| GET | `/api/goals/{id}` | Bearer | 3 | One goal with projection. `404` if missing or another user's |

| DELETE | `/api/goals/{id}` | Bearer | 3 | Delete a goal. `204`, `404` |

## Status codes used

| Code | Meaning in this API |
|---|---|
| 200 | Success |
| 201 | Resource created |
| 202 | Accepted: work started in the background (pipeline job) |
| 204 | Deleted; no body |
| 401 | Not authenticated (no, invalid or expired token; wrong credentials) |
| 403 | Authenticated but not allowed (e.g. admin-only) |
| 404 | Resource does not exist yet (e.g. profile not created, no assessment), or belongs to another user |
| 409 | Conflict (e.g. email already registered; assessment before profile; simulating a goal that is due, or a history-based model before market data is loaded; retirement plan before a profile; editing the goal that the retirement planner owns; an ML model that has not been trained yet; a recommendation without enough market data) |
| 422 | Validation failed; body lists each failing field |
