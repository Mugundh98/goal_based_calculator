# API

_Living document – updated whenever endpoints are added. Last updated: Phase 5._

The complete, interactive specification is generated by FastAPI at **`/docs`** (Swagger UI, with an **Authorize** button for protected endpoints) and **`/openapi.json`**.

**Authentication:** protected endpoints require the header `Authorization: Bearer <access_token>`, obtained from `POST /api/auth/login`. Tokens expire after 60 minutes.

| Method | Path | Auth | Phase | Purpose |
|---|---|---|---|---|
| GET | `/api/health` | None | 0 | API status and database/pgvector connectivity |
| POST | `/api/auth/register` | None | 1 | Create an account (JSON). `201`, `409` duplicate email, `422` invalid input |
| POST | `/api/auth/login` | None | 1 | OAuth2 password flow (form: `username`, `password`) → access token. `401` on bad credentials |
| GET | `/api/auth/me` | Bearer | 1 | The logged-in user. `401` if token missing, invalid or expired |
| GET | `/api/profile` | Bearer | 2 | The user's financial profile (+ age, monthly surplus). `404` if not created |
| PUT | `/api/profile` | Bearer | 2 | Create or replace the financial profile. `422` invalid |
| GET | `/api/risk/questionnaire` | Bearer | 2 | Questions and options (no points) |
| POST | `/api/risk/assessments` | Bearer | 2 | Score answers + profile, store result. `409` no profile, `422` bad answers |
| GET | `/api/risk/assessments` | Bearer | 2 | Assessment history, newest first |
| GET | `/api/risk/assessments/latest` | Bearer | 2 | Most recent assessment. `404` if none |
| GET | `/api/goals` | Bearer | 3 | The user's goals, each with a projection; by priority, then target year |
| POST | `/api/goals` | Bearer | 3 | Create a goal. `201`, `422` invalid (e.g. target year not in the next 1–60 years) |
| POST | `/api/goals/calculate` | Bearer | 3 | Project goal numbers without saving (live preview) |
| GET | `/api/goals/{id}` | Bearer | 3 | One goal with projection. `404` if missing or another user's |
| PUT | `/api/goals/{id}` | Bearer | 3 | Replace a goal. `404`, `422` |
| DELETE | `/api/goals/{id}` | Bearer | 3 | Delete a goal. `204`, `404` |
| GET | `/api/funds` | Bearer | 4 | Search (`q`: name, fund house, scheme code), filter (`asset_class`, `category`, `plan`, `option`, `active_only`), sort (`sort`, `order`; missing metrics last) and page (`page`, `page_size` ≤ 100) funds → `{items, total, page, page_size}` |
| GET | `/api/funds/categories` | Bearer | 4 | Asset class + category pairs with fund counts (for the filters) |
| GET | `/api/funds/{id}` | Bearer | 4 | Fund details with metrics (or `null`), `is_active`, benchmark. `404` |
| GET | `/api/funds/{id}/nav` | Bearer | 4 | Daily NAVs for `period` = 1y, 3y (default), 5y, 10y, max. `404`, `422` |
| GET | `/api/market/summary` | Bearer | 4 | Fund counts, latest NAV date, index levels with 1-year return, latest CPI inflation, last run of each job |
| GET | `/api/market/indices/{symbol}/history` | Bearer | 4 | Daily closes from `start` (e.g. `^NSEI`, URL-encoded `%5ENSEI`). `404` unknown index |
| GET | `/api/market/inflation` | Bearer | 4 | Monthly CPI with year-on-year inflation |
| GET | `/api/market/jobs` | Bearer | 4 | Pipeline log (`job_runs`), newest first; `job_name`, `limit` ≤ 100 |
| POST | `/api/market/jobs/{job}/run` | Bearer, **admin** | 4 | Start a pipeline job in the background. `202`, `403` not admin, `404` unknown job |
| POST | `/api/goals/{id}/simulate` | Bearer | 5 | Monte Carlo simulation of a goal, **not saved** (what-if sliders). Body: `model` (bootstrap default, normal, garch, hmm), `paths` 500–10,000, `seed`, `overrides` {`monthly_sip`, `step_up_rate`, `target_year`, `equity_percent`}. `404` goal, `409` goal due or model needs market data, `422` |
| POST | `/api/goals/{id}/simulate/compare` | Bearer | 5 | All four models on the same inputs and seed (only `normal` without market data). `404`, `409`, `422` |
| POST | `/api/goals/{id}/simulations` | Bearer | 5 | Run and **save** a simulation (snapshot). `201`, `404`, `409`, `422` |
| GET | `/api/goals/{id}/simulations` | Bearer | 5 | Saved runs of a goal, newest first, without the bands. `404` |
| GET | `/api/simulations/{id}` | Bearer | 5 | A saved run, exactly as it was returned when made. `404` if missing or another user's |
| DELETE | `/api/simulations/{id}` | Bearer | 5 | Delete a saved run. `204`, `404` |

## Status codes used

| Code | Meaning in this API |
|---|---|
| 200 | Success |
| 201 | Resource created |
| 202 | Accepted: work started in the background (pipeline job) |
| 204 | Deleted; no body |
| 401 | Not authenticated (no, invalid or expired token; wrong credentials) |
| 403 | Authenticated but not allowed (e.g. admin-only) |
| 404 | Resource does not exist yet (e.g. profile not created, no assessment), or belongs to another user |
| 409 | Conflict (e.g. email already registered; assessment before profile; simulating a goal that is due, or a history-based model before market data is loaded) |
| 422 | Validation failed; body lists each failing field |
